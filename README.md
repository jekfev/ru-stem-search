# Russian Stem Search

Плагин WordPress: быстрый поиск по основам русских слов. Штатный поиск WordPress не знает морфологии: «дорога», «дороги», «дорогу» для него разные слова, а на большом архиве он ещё и медленный (LIKE по всему тексту).

## Что делает
- Приводит слова к основе (русский стеммер Snowball, собственная реализация, без зависимостей) и ищет по полнотекстовому индексу MySQL InnoDB. «Дорога», «дороги», «дорогу» дают один результат.
- Любой порядок слов, поиск по началу слова, «фраза в кавычках», `ё` = `е`.
- Заголовок весит больше текста: статьи со словом в заголовке идут первыми; при прочих равных свежее выше.
- Все слова запроса обязательны; если ничего не нашлось, показываются записи хотя бы с одним из слов.
- Запрос выполняется за сотые доли секунды (на архиве в 15 тысяч статей: 0,01–0,07 с против ~0,9 с у штатного поиска).
- Подменяет запрос на странице поиска темы и любой `WP_Query` с параметром `s` на сайте. Шаблоны темы не меняет.

## Установка
1. Скопируйте папку в `wp-content/plugins/` и активируйте плагин (или положите `ru-stem-search.php` в `wp-content/mu-plugins/`).
2. **Инструменты → Русский поиск → «Построить индекс заново».** Пока индекс не построен, работает штатный поиск WordPress; после сборки новый поиск включается сам.
   Либо через WP-CLI: `wp sg-search rebuild`.
3. Новые и изменённые записи попадают в индекс автоматически.

Проверка: `wp sg-search test дороги` покажет основы слов, число найденных и первые 10 результатов.

## Требования
WordPress 5.0+, PHP 7.1+ (код совместим и с PHP 8.x), MySQL 5.6+/MariaDB 10.0+ с InnoDB. Индексируются записи и страницы со статусом «опубликовано» (кроме защищённых паролем).

## Как устроено
Таблица `{prefix}sg_search` (post_id, основы заголовка, основы текста, FULLTEXT-индексы). Удаление плагина через админку удаляет таблицу и опции.

## Ограничения
- Стеммер режет разные формы одного слова по-разному в редких случаях (например, «урожай» и «урожая»), поэтому число результатов для них может немного отличаться.
- Поиск по основе слова захватывает однокоренные слова («дороги» найдёт и «дорогие»): это цена полноты.
- Только русский язык. Другие слова остаются как есть.
